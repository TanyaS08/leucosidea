# Leucosidea — grassland community study

This repository contains the data, analysis scripts and outputs for the study of Leucosidea's effects on grassland communities.

Contents
- data/         : original and processed data (see data/README.md)
- scripts/      : numbered R scripts that perform the analyses
- figures/      : generated figures used in the manuscript
- outputs/      : tables and result CSVs
- renv.lock     : recorded R package versions for reproducibility

Quick start
1. Install R (>= 4.0) and RStudio (recommended).
2. Clone the repo and open `GGHNP.Rproj` in RStudio or set the project root in R.
3. Restore packages: run

   renv::restore()

4. Run the analysis scripts (in order) from the project root. Example to run all scripts:

   lapply(list.files("scripts", pattern = "^0", full.names = TRUE), source)

Notes on scripts
- scripts/_internals.R contains helper functions and is sourced by the numbered scripts.
- Scripts are ordered to reflect the manuscript workflow. The main analysis scripts include:
  - scripts/01_microclimate.R
  - scripts/02_chi_squared.R
  - scripts/03_nmds.R
  - scripts/04_funtional_traits.R

Reproducibility
- renv is used to pin package versions. After cloning, run renv::restore() to recreate the environment.
- Outputs (figures/ and outputs/) are generated by the scripts — remove them and re-run scripts to reproduce results.

Data
- See data/README.md for details on each dataset. Sensitive or proprietary data included in this repo should be handled according to the project data policy.
